# Живой блокнот

Локальное приложение для заметок: живой лист на день, автоматическая ветка, сроки, корзина, обучение на исправлениях и аудит действий. Работает офлайн в браузере, данные — в IndexedDB, без сервера и аккаунта.

## Быстрый старт

```bash
npm install     # один раз
npm test        # 217 тестов, node:test
npm run dev     # http://localhost:8080
```

Открыть `http://localhost:8080`. Первый запуск создаёт 5 seed-заметок.

**Полное руководство «с нуля до приложения на телефоне» — [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md).**

## Телефон

- **GitHub Pages (PWA, уже работает):** `https://dropingcat.github.io/livenotepad/` — HTTPS, установка на домашний экран Android, офлайн.
  - Chrome → меню **⋮** → **«Установить приложение»** (или «Добавить на главный экран») → «Установить» → иконка на экране.
  - Запуск с иконки: отдельное окно без адресной строки.
  - Проверка: авиарежим → закрыть → открыть — лист и данные на месте.
  - Подробно про установку, отличия от вкладки, офлайн и разбор проблем: [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md), [docs/PWA.md](docs/PWA.md).
- **LAN (для отладки):** `http://192.168.1.100:8080` — та же Wi-Fi (`netis-Fox-5G`); порт открыт только для `192.168.1.0/24`. LAN HTTP — не secure context: нет `crypto.subtle`/`randomUUID`, install PWA недоступен; для полного функционала — Pages.

Подробности и ограничения: [docs/PREVIEW.md](docs/PREVIEW.md).

## Аудит

Монитор (📊) → вкладка **Логи** → **Скачать аудит**. Файл `livenotepad-audit-*.json` содержит все события и ошибки сессии: `APP_START`, действия с заметками, импорт/экспорт, `ERROR` с контекстом и стеком.

После теста сохраните файл и передайте на разбор. Как читать: [docs/AUDIT.md](docs/AUDIT.md).

## Структура

```
www/                 приложение (index.html + js-модули)
  js/                constants, time, stopwords, distance, stemmer,
                     classifier, due-parser, due-state, live-sheet,
                     branches, note-edit, dedup, import, idb, audit
test/                node:test, чистые модули
scripts/             dev-сервер
docs/                спеки, планы, архитектура, превью, аудит
.runs/               рантайм фабрики: отчёты, снапшоты, журнал (не в git)
```

## Принципы

- Текст заметки всегда выше контекста; контекст — только последний fallback.
- Галочка не обучает; правка текста не меняет ветку; переоткрытие не меняет ветку.
- Импорт не удаляет данные без явного «заменить всё» и резервной копии.
- Любое значимое действие и ошибка оставляют запись в аудите.
