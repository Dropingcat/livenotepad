# Начало работы — от ссылки до приложения на телефоне

Это пошаговое руководство «с нуля»: что это за приложение, как открыть его на компьютере и на телефоне, что означает пункт **«Установить приложение»**, зачем нужен авиарежим и как сохранить аудит после теста.

Если вам нужно только короткое «открой ссылку → меню → установить», это в [README](../README.md#телефон). Здесь — подробно, с объяснением каждого шага и разбором проблем.

---

## 0. Что это

**«Живой блокнот»** — приложение для заметок, которое:

- живёт **в браузере**, но устанавливается на телефон как обычное приложение;
- хранит все данные **локально на устройстве** (IndexedDB), без сервера и аккаунта;
- **работает офлайн** — код и стили кэшируются, заметки лежат в памяти браузера;
- не требует APK, Google Play или App Store.

Технически это **PWA** (Progressive Web App): сайт с манифестом, service worker и иконками. Браузер умеет «забирать» такой сайт на домашний экран и запускать его в отдельном окне.

Адрес приложения: **https://dropingcat.github.io/livenotepad/**

---

## 1. Открыть на компьютере

1. Откройте ссылку **https://dropingcat.github.io/livenotepad/** в Chrome / Edge / Firefox.
2. При первом запуске появятся 5 стартовых заметок.
3. Всё уже работает: можно писать, отмечать, менять сроки.

Это же приложение можно поднять локально для разработки:

```bash
npm install      # один раз
npm run dev      # http://localhost:8080
npm test         # 217 тестов
```

`localhost` — тоже защищённый контекст, поэтому установка PWA и полный функционал доступны и там.

## 2. Что значит «Установить приложение»

**Коротко:** это кнопка в меню Chrome, которая превращает открытую страницу в **ярлык-приложение на домашнем экране телефона**. Открывается в отдельном окне, без адресной строки браузера. Никаких APK и магазинов.

### Почему браузер это умеет

У сайта есть три вещи, которые Chrome считает признаками «настоящего приложения»:

| Что | Файл | Зачем |
|---|---|---|
| Манифест | `www/manifest.webmanifest` | имя, иконки, цвет темы, `display: standalone`, `start_url` |
| Service worker | `www/sw.js` | офлайн-работа: кэш кода/стилей/иконок, network-first |
| HTTPS | `https://dropingcat.github.io` | без защищённого контекста установка невозможна |

Когда все три на месте, Chrome показывает пункт **«Установить приложение»**.

### Как это выглядит по шагам (Android, Chrome)

1. Откройте **https://dropingcat.github.io/livenotepad/** в **Google Chrome**.
2. Нажмите **⋮** (три точки) в правом верхнем углу.
3. В меню выберите:
   - **«Установить приложение»** — если пункт есть (даёт standalone-окно), **или**
   - **«Добавить на главный экран»** — если первого нет (ярлык, откроется во вкладке).
4. В диалоге будет иконка и название **«Живой блокнот» / «Блокнот»** → нажмите **«Установить»**.
5. На домашнем экране появится иконка **«Блокнот»**.
6. Нажмите на неё — приложение откроется **без адресной строки**, как обычное приложение.

> Названия пунктов немного отличаются между версиями Chrome и прошивками Android. Смысл один: «сделать ярлык-приложение из этой страницы».

### Чем установленное приложение отличается от вкладки

| | Открыто в вкладке Chrome | Установлено как приложение |
|---|---|---|
| Где открывается | внутри Chrome, с адресной строкой и вкладками | отдельное окно, без строки браузера |
| Иконка на домашнем экране | нет | есть («Блокнот») |
| Офлайн | работает, пока вкладка жива | работает как самостоятельное окно, надёжнее |
| Перезапуск | через вкладку/историю | как у обычного приложения |
| В списке недавних задач | вкладка Chrome | отдельное приложение |

Обе версии — **одно и то же приложение с одними и теми же данными** (один origin → одна IndexedDB). Разница только в оболочке запуска.

## 3. Проверка офлайна (авиарежим)

Это не отдельная функция, а **проверка**, что приложение действительно установлено и работает без интернета.

1. Включите **авиарежим** (отключите и Wi-Fi, и мобильные данные).
2. **Закройте** приложение: смахните его из списка открытых окон (кнопка «недавние»).
3. **Откройте** его снова с иконки на домашнем экране.

Ожидаемый результат: приложение запускается, лист заметок на месте, данные не пропали.

**Почему это работает:** service worker сохранил все нужные файлы (HTML, JS, стили, иконки) в кэш телефона. Ваши заметки лежат в IndexedDB прямо на устройстве. Сеть для запуска не нужна.

Если при авиарежиме открывается пустой экран или ошибка — значит service worker не активировался. См. раздел 6.

## 4. Сохранить аудит после теста

Аудит — это журнал всех действий и ошибок сессии. Он нужен, чтобы разбирать проблемы без догадок.

1. Откройте **Монитор** (кнопка 📊).
2. Перейдите на вкладку **Логи**.
3. Нажмите **«Скачать аудит»**.
4. Файл `livenotepad-audit-*.json` сохранится в **Downloads** (Chrome) или откроется системное «Поделиться» (Safari).
5. Если скачивание не сработало — нажмите **«Копировать»** и вставьте содержимое в заметку/мессенджер.

Что внутри файла: `format`, `version`, `exportedAt`, `appVersion`, `sessionId`, `deviceId`, `userAgent`, `platform`, `counts` (`events`/`errors`/`failed`), `pending`, `lost`, `events[]`.

**Важно:**
- Полный текст заметок **не пишется** — только первые 100 символов (чтобы не утекали личные записи).
- **Не делайте «Сброс» до сохранения аудита** — текущий сброс очищает журнал. Безопасный сброс с резервными копиями появится в карте `AUD-002d`.
- Пришлите файл на разбор — так проблема видна точно, а не «на глаз».

Как читать аудит: [docs/AUDIT.md](AUDIT.md).

## 5. Где хранятся данные (и почему это важно)

- Данные лежат **локально**, в IndexedDB браузера, и **привязаны к адресу сайта (origin)**.
- Заметки с `https://dropingcat.github.io/livenotepad/` **не появятся** на `http://192.168.1.100:8080` и наоборот — это разные origin, разные хранилища.
- Синхронизации между устройствами **нет** (осознанное ограничение): перенос — только через экспорт/импорт файлами.
- Очистка данных сайта в настройках Chrome **удалит заметки**. Экспорт/резервные копии — в карте `AUD-002b/002d`.

## 6. Если что-то не так

### В меню Chrome нет «Установить приложение»

Причины и что делать:

1. **Открыто не в Chrome.** Установка PWA — в Chrome (или Edge). Встроенные браузеры мессенджеров (Telegram, VK, Instagram и т.п.) установку не предлагают — откройте ссылку именно в Chrome.
2. **Страница ещё не «созрела».** Chrome иногда показывает пункт не сразу: обновите страницу и подождите пару секунд.
3. **Открыт не HTTPS.** Установка возможна только на `https://…` или `localhost`. Наш адрес — HTTPS, тут всё в порядке; проблема может быть, если вы открыли LAN-адрес `http://192.168.1.100:8080` — с него установка невозможна (это для отладки).
4. **Нет пункта «Установить», но есть «Добавить на главный экран».** Используйте его — приложение тоже появится на экране.
5. **Совсем нет ни того, ни другого.** Откройте сайт во вкладке (он полностью рабочий), соберите аудит (раздел 4) и пришлите — разберём.

### Приложение открывается, но пустое / ошибка при офлайне

- Убедитесь, что первый запуск был **онлайн** и вы дали странице загрузиться полностью (service worker ставится при первом визите).
- Закройте приложение и откройте снова онлайн — SW активируется и закэширует файлы.
- Проверьте интернет: при самом первом визите он нужен.

### «Скачать аудит» не сохраняет файл

- Нажмите **«Копировать»** — содержимое попадёт в буфер, вставьте в заметку/сообщение.
- Проверьте разрешение Chrome на скачивание файлов.
- URL файла отзывается через 1 секунду после клика — если телефон очень медленный, повторите нажатие.

### Данные «пропали» после переустановки

- Скорее всего, вы открыли другой origin (LAN вместо Pages) или очистили данные сайта.
- Данные одного origin не переходят на другой автоматически. Для переноса — экспорт из одного, импорт в другой (импорт **объединяет**, не удаляет).

## 7. Ограничения текущей версии (осознанные)

- **Нет фоновых уведомлений о сроках** — достаточно бейджа и списка «Просрочено» при открытии.
- **Нет синхронизации между устройствами** — только локальные данные + файлы.
- **Нет нативных share/haptics/splash/deep links** — это будущая Capacitor-оболочка (APK), не PWA.
- **Аудит и заметки — в IndexedDB телефона**; выгрузка вручную.
- **Сброс пока небезопасен** (нет резервных копий) — не делайте его до сохранения аудита.

Подробнее про PWA-срез и обновления: [docs/PWA.md](PWA.md). Про LAN-превью: [docs/PREVIEW.md](PREVIEW.md).
